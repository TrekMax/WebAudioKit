# ADR-012：采样率转换只模拟非破坏式监听效果

- 状态：Accepted
- 日期：2026-08-07
- 更新：2026-08-08

## 背景

节点编译器需要增加可配置上/下采样的采样器节点，同时项目仍要求源 PCM 不可变、播放不中断、内存有界。Web Audio 图中的所有中间节点最终必须按 AudioContext 的固定采样率输出，不能由单个节点真正改变声卡或图的采样率。

## 决策

- 采样器属于湿声监听分支，不进入源 PCM、权威 FFT/STFT 或导出管线。
- 目标采样率范围为 3–192 kHz。低于 AudioContext 采样率时，AudioWorklet 使用有界一阶低通预滤波，再按相位累加器抽取；声明式配置保存 `hold | linear | cubic | sinc` 算法，默认 `hold` 保留既有听感与配置兼容性。
- `hold` 对抽取值执行零阶保持；`linear` 在前后两个抽取值间因果线性重建，引入一个目标采样间隔延迟；`cubic` 用四点 Catmull–Rom 重建并使用两个目标采样间隔的因果历史；`sinc` 使用构造期预计算的 128 相位、16 抽头 Lanczos 窗化 sinc 系数表，并固定延迟八个目标采样间隔。
- 目标采样率不低于 AudioContext 采样率时界面显示“透明直通”、禁用算法选择，并由 Worklet 直接复制输入；AudioBufferSourceNode 到 AudioContext 的原生转换已完成必要插值，但不宣称增加 PCM 帧数或产生超过上下文 Nyquist 的新频率信息。
- 算法通过 `processorOptions` 进入 Worklet，切换算法时在控制线程替换当前监听路由；目标采样率继续使用 k-rate AudioParam 原位更新。
- Worklet 构造阶段预分配最多 32 声道、每声道 16 个历史样本的滤波与相位状态；仅 `sinc` 模式在构造期创建固定 128×16 系数表。实时 `process()` 不分配对象或 TypedArray，不执行日志、I/O、Promise、动态导入、数组扩容或无界循环；最重路径固定为每输出样本 16 次乘加。
- AudioWorklet 不可用或模块加载失败时使用 GainNode 透明旁路。模块就绪后在控制线程原子替换湿声链并释放旧节点。
- 频谱预览为抗混叠响应叠加对应重建近似：`hold` 保持基线，`linear` 使用 `sinc²`，`cubic` 对 16 个分数相位的 Catmull–Rom 响应取平均，`sinc` 使用目标 Nyquist 附近的带限过渡。它是监听预测，不替代效果后 PCM 的权威 STFT。
- A/B 波形 B 轨只处理当前可视时间范围，并使用与绘图区像素数对应的固定列数和每列取样预算；存在多个活动下采样采样器时选择最低目标采样率节点表达主导时域效果。源 PCM 通过线性插值近似适配到 AudioContext 采样率，再按 Worklet 的四种相位和重建规则计算，并以每个取样点前最多 64 个上下文采样帧的局部预热近似一阶低通状态；该流程不扫描或复制整段 PCM，因此不作为效果后 PCM 的权威结果。

## 结果

优点：

- 可在不中断播放和不复制整段 PCM 的前提下比较采样率降低的听感。
- 可在颗粒保持、低成本线性、三次平滑与带限重建之间切换，并保留相同的抗混叠基线。
- 实时线程的工作与声道数、render quantum 长度成固定上限关系，符合实时安全约束。
- 不支持 AudioWorklet 的浏览器仍能播放，且不会静音或破坏源数据。

限制：

- 这是实时监听效果，不是高质量离线重采样器，也不会改变 WAV 导出的采样率。
- 一阶抗混叠仍侧重实时成本，不等同于专业离线 SRC 的高阶抗混叠滤波。
- 线性、三次与带限模式分别存在约一、二、八个目标采样间隔的因果延迟；A/B 试听不自动做延迟补偿。
- 超过 32 声道时额外声道透明直通；常规浏览器输出布局不会触及该上限。
