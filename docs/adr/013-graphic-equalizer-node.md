# ADR-013：EQ 曲线节点使用固定七段 Biquad 分组

- 状态：Accepted
- 日期：2026-08-08

## 背景

节点编译器需要支持可视化 EQ 曲线调节，同时继续满足本地优先、非破坏式监听、播放不中断和运行成本有界的产品边界。单个 BiquadFilterNode 只能表达一个滤波段，任意控制点 IIR 设计则会增加稳定性、迁移与跨浏览器一致性风险。

## 决策

- 一个声明式 EQ 节点固定包含 60 Hz、150 Hz、400 Hz、1 kHz、2.5 kHz、6 kHz 与 15 kHz 七个频段，每段仅保存 `[-24, 24] dB` 增益，Q 固定为 1.1。
- 编译器将该节点展开为七个串联的原生 Peaking BiquadFilterNode。运行路由保留声明式节点到 AudioNode 分组的映射，增益变化原位更新七个节点，不重建播放源或效果链。
- 悬浮面板使用对数频率、线性 dB 坐标绘制控制曲线；拖点值按 0.5 dB 量化，并提供键盘、滑杆、数值输入和整曲线归零路径。
- B 轨频谱与二维声谱预览累加七个运行时 Biquad 的实际幅频响应。EQ 仍只属于湿声监听分支，不进入源 PCM、权威分析或导出。
- 配置复制必须深拷贝频段数组，校验必须拒绝频段数量或增益范围不合法的数据。

## 结果

优点：

- EQ 运行成本和配置大小固定，可使用浏览器原生滤波器获得稳定、可查询的响应。
- 曲线连续拖动不会重启播放，A/B 预览与实际监听图使用相同的七段参数。
- 固定中心频率降低了交互复杂度，并避免任意滤波器系数带来的稳定性风险。

限制：

- 首版是七段图示 EQ，不支持增删频段、拖动中心频率、独立 Q、动态 EQ 或自动化。
- 控制曲线用于表达各段目标增益；精确组合响应以 Web Audio Biquad 响应和 B 轨预览为准。
