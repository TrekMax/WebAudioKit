# ADR-013：EQ 曲线节点使用固定预设 Biquad 分组

- 状态：Accepted
- 日期：2026-08-08

## 背景

节点编译器需要支持可视化 EQ 曲线调节，同时继续满足本地优先、非破坏式监听、播放不中断和运行成本有界的产品边界。单个 BiquadFilterNode 只能表达一个滤波段，任意控制点 IIR 设计则会增加稳定性、迁移与跨浏览器一致性风险。

## 决策

- 一个声明式 EQ 节点可选择 7、10 或 15 段固定预设，默认采用 10 段倍频程预设。7 段为 60 Hz、150 Hz、400 Hz、1 kHz、2.5 kHz、6 kHz 与 16 kHz，Q 为 1.1；10 段为 31.5 Hz、63 Hz、125 Hz、250 Hz、500 Hz、1 kHz、2 kHz、4 kHz、8 kHz 与 16 kHz，Q 为 `√2`；15 段为 25 Hz、40 Hz、63 Hz、100 Hz、160 Hz、250 Hz、400 Hz、630 Hz、1 kHz、1.6 kHz、2.5 kHz、4 kHz、6.3 kHz、10 kHz 与 16 kHz，Q 为 2.15。每段仅保存 `[-24, 24] dB` 增益。
- 编译器按所选预设将该节点展开为相同数量的串联原生 Peaking BiquadFilterNode。运行路由保留声明式节点到 AudioNode 分组的映射；同档增益变化原位更新，不重建播放源或效果链。切换档位时按对数频率线性插值已有增益，并替换 EQ 运行时分组，但不重建或重启播放源。
- 悬浮面板使用对数频率、线性 dB 坐标绘制控制曲线；拖点值按 0.5 dB 量化，并提供键盘、滑杆、数值输入和整曲线归零路径。
- B 轨频谱与二维声谱预览累加当前 EQ 分组内全部运行时 Biquad 的实际幅频响应。EQ 仍只属于湿声监听分支，不进入源 PCM、权威分析或导出。
- 配置复制必须深拷贝频段数组，校验必须拒绝频段数量或增益范围不合法的数据。

## 结果

优点：

- 每档 EQ 运行成本和配置大小有界，可使用浏览器原生滤波器获得稳定、可查询的响应。
- 曲线连续拖动与档位切换都不会重启播放，A/B 预览与实际监听图使用相同的预设参数。
- 行业常用的倍频程与 2/3 倍频程中心频率降低了交互复杂度，并避免任意滤波器系数带来的稳定性风险。

限制：

- 三档预设不支持任意增删频段、拖动中心频率、独立 Q、动态 EQ 或自动化。
- 单个 EQ 在 15 段模式下使用 15 个串联 Biquad，极端多 EQ 链路的实时成本高于默认 10 段模式。
- 控制曲线用于表达各段目标增益；精确组合响应以 Web Audio Biquad 响应和 B 轨预览为准。
